## Tentang Project

Project ini adalah website dinamis berbasis PHP yang menampilkan konten seputar dunia One Piece. Fitur utama meliputi sistem login dengan dua role berbeda (admin dan user), serta pengelolaan data menggunakan operasi CRUD.

## Teknologi

- HTML, CSS, JavaScript
- PHP native (tanpa framework)
- MySQL

## Fitur

- Login dan registrasi
- 2 role akun: Admin dan User
- CRUD data
- Validasi form
- Session management
